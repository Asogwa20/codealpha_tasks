Welcome to EngiCalc Pro

Your engineering and mathematical workspace for scientific calculations, complex numbers, matrices, calculus, graphing, electrical engineering, and unit conversions.

How to use this application

  1. Use the navigation menu to choose a calculation module.
  2. Enter your values or expression in the input fields.
  3. Press the calculate, evaluate, or plot button to see results.
  4. Review formulas, methods, units, and any validation messages shown.
  5. Open History to revisit or reuse previous calculations.

Quick navigation guide

  1. Scientific Calculator — perform everyday and advanced mathematical calculations.
  2. Complex Numbers — calculate with real and imaginary numbers.
  3. Matrices — perform matrix operations.
  4. Calculus — explore numerical differentiation, integration, limits, and equation solving.
  5. Quadratic Solver — solve ax² + bx + c = 0, analyze roots, and verify solutions.
  6. Graphing — plot mathematical functions.
  7. Electrical Engineering — solve common electrical engineering calculations.
  8. Conversions & Constants — convert units and access useful scientific constants.
  9. Binary Calculator — convert number bases, do binary arithmetic, bitwise operations, and view two's-complement representations.
  10. History — review previous calculations.

Help / Quick Guide

EngiCalc Pro is a browser-based engineering workspace. Choose a module from the left menu, enter inputs, and use the action buttons to calculate or plot.

Module tips

  • Scientific Calculator: type expressions like 2*sin(pi/4)+sqrt(9). Use Degrees/Radians for trig functions. Press Enter to evaluate.
  • Complex Numbers: enter real and imaginary parts for A and B, choose an operation, and calculate. Results show rectangular and polar forms where relevant.
  • Matrices: set dimensions, build matrices, fill values, then choose an operation. The app explains dimension or invertibility errors.
  • Calculus: enter f(x) and required values. Results are numerical approximations and include a short method explanation.
  • Quadratic Solver: enter coefficients a, b, and c for ax² + bx + c = 0. The solver shows the discriminant, root type (distinct real, repeated real, or complex conjugate), quadratic formula steps, and substitution verification. If a = 0, it explains the equation is not quadratic and solves it as linear when possible.
  • Graphing: enter f(x), set x-range and samples, then generate the graph. Invalid points are reported clearly.
  • Electrical Engineering: select a tool, provide known values, and calculate. Formulas, substituted values, units, and results are shown.
  • Conversions & Constants: pick a category/unit pair to convert, or browse constants with values and units.
  • Binary Calculator: choose a conversion, arithmetic, bitwise, or representation operation. Use the bit width for signed two's-complement/fixed-width behavior. Results include explanations, quotient and remainder for division, and overflow/two's-complement limitations. Calculations use BigInt (not 32-bit JavaScript bitwise operators).
  • History: saved calculations persist after refresh. Reuse loads supported inputs back into the relevant module.

Important notes

  • Calculus and graphing results can be numerical approximations.
  • Always check units in electrical calculations.
  • If you see an error, adjust inputs (for example avoid division by zero, invalid domains, or incompatible matrix sizes).
